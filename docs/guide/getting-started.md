# Getting started

Better Campfire Pot is a Cobblemon addon that makes the campfire pot faster and easier to automate with hoppers, pipes and autocrafting mods such as Applied Energistics 2 and Refined Storage.

## Install

| Platform | Link |
| --- | --- |
| CurseForge | [Download from CurseForge](https://www.curseforge.com/minecraft/mc-mods/cobblemon-better-campfire-pot) |
| Modrinth | [Download from Modrinth](https://modrinth.com/mod/cobblemon-better-campfire-pot) |

1. Install [Fabric](https://fabricmc.net/) or [NeoForge](https://neoforged.net/) for Minecraft **1.21.1**.
2. Install [Cobblemon](https://modrinth.com/mod/cobblemon) and the other dependencies below.
3. Put the Better Campfire Pot jar in your `mods` folder.

## Your first better pot

**1. Craft a copper pot.** Surround any Cobblemon campfire pot with copper ingots. The pot keeps its colour.

<RecipeCard result="bettercampfirepot:copper_red_campfire_pot" />

**2. Use it like a normal campfire pot.** Put it on a campfire and open it. Ingredients can go in **any** input slot: the recipe's grid pattern does not matter, so you can stack everything together.

**3. Go faster.** Craft the copper pot up through Iron, Gold, Diamond, Emerald and Netherite, or use an [upgrade item](./upgrade-items) on a pot that is already placed.
